Edit an existing PDF or Word CV

Treat an imported document as a reference and review the result carefully.

Start with the essentials

Use PDF replacements for small corrections where you can place text accurately. Coordinates are measured in page points from the top left. White covers are visual overlays, not secure redaction.

Make the structure clear

DOCX imports extract editable text and rebuild a clean Word document. Preserve the original separately if you need complex tables, photographs or a branded layout.

Check the details

Choose the correct file before reserving an edit credit. Review the preview and all wording before finalizing: one credit produces one final version.

Review before sharing

Check the downloaded file in a PDF or Word reader. If a reservation failed before finalization, contact support with the edit session ID, excluding confidential document content.
