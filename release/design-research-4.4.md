# Medico 4.4 design review

Primary references reviewed: [Linear's design refresh](https://linear.app/now/behind-the-latest-design-refresh), [Raycast](https://www.raycast.com/) and [Things](https://culturedcode.com/things/). Their compact navigation, clear hierarchy and restrained motion informed an original MedCV homepage. No third-party template designs were copied.

The homepage has one Create my CV action, eight career categories, a tools dialog, an appearance section and a bounded document tilt. Reduced-motion preferences disable movement. Mira is a bottom-right robot opening a keyboard-accessible dialog; unanswered questions survive closing it.

There are exactly ten free catalogue templates. The other 86 original designs require account-specific server unlocks. Mira lists free and verified unlocked designs only. Premium preview and download recheck server access. Cached local configuration is not an entitlement. Original custom designs remain separate from catalogue templates.

Referral credits use verified server completion, unique identities, an atomic ledger and idempotent unlocks. Installing the app alone does not qualify a referral; the referred account must verify its first qualifying CV. Premium access requires a network connection to verify ownership. Downloaded files cannot be recalled, and offline client code cannot provide DRM against deliberate modification.
