# Template research and ownership

All 96 MedCV designs in this release are original ChoiceMatrix layouts built by composing the app's PDF renderer. No third-party paid template, screenshot, stylesheet or template code was copied. Premium means a verified referral unlock, not an assertion that a design was purchased from another site.

Professional resume conventions were researched across these public, separately licensed projects:

- JSON Resume registry/themes: https://jsonresume.org/themes
- Even theme (MIT): https://github.com/rbardini/jsonresume-theme-even
- Class theme: https://github.com/jsonresume/jsonresume-theme-class
- Actual theme: https://github.com/davcd/jsonresume-theme-actual
- OpenResume: https://github.com/xitanggg/open-resume

These sources are references, not bundled dependencies. Their licenses remain applicable to their own assets. Exported personal CVs may be used for applications; the MedCV template library is not licensed for competing redistribution. User uploads require the user's right to edit their original document.
